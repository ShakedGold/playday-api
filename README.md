# Playday API
This is the playday API repository, here all of the logic code of Playday is written, for UI go to: https://github.com/ShakedGold/playday-ui.git

## Building
This is not meant to be built directly, but be used as a zig module in the UI project.

## Dependencies
- `playday-vdf` in order to parse vdf files: https://github.com/ShakedGold/playday-vdf.git
